# Agent Instructions

## Python Environment
- Always use the Python virtual environment located in the project root: `./venv` (or `~/dev/Calli/venv`), using Python version 3.13.
- Do NOT use the global virtual environment (`~/_dj`) mentioned in the global instructions.
- Execute Python commands and scripts using `./venv/bin/python` and `./venv/bin/pip` (or by activating `source venv/bin/activate`).
- Use ./tmp when you need to write something to /tmp. Do not write anything in /tmp
- Read .env file
